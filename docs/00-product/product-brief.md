# Product Brief — NeighBid

## Concept

NeighBid is a neighbourhood service bidding platform.

Homeowners, especially those in HOA communities, can group together for common home services and trigger competitive bids from local service providers.

The goal is to turn isolated individual service requests into group buying power.

## Primary Problem

Homeowners usually:
- search for providers independently
- receive expensive individual quotes
- lack price transparency
- miss chances to coordinate with neighbours
- cannot trigger competitive provider bidding

## Core Solution

NeighBid creates a shared service request flow:

1. A homeowner posts a service need.
2. The system detects similar needs in the neighbourhood.
3. A service group/thread is created.
4. Providers submit competing bids.
5. Homeowners compare bids transparently.
6. The best provider is selected based on price, rating, and trust.

## Initial Build Goal

Build the website UI/UX first.

Do not build production backend/AI/database features yet.

The website should show the complete product vision through:
- polished landing page
- role-based onboarding
- homeowner dashboard
- service request flow
- bidding room UI
- provider dashboard
- HOA admin preview
- placeholder AI assistant interaction
- mock data

## Target Devices

- laptop browser
- mobile browser

This is a responsive website, not a native app for the first version.
