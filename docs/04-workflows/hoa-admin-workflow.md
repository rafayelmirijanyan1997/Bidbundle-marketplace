# HOA Admin Workflow

## Ideal Flow

1. Admin selects HOA Admin role.
2. Admin opens community dashboard.
3. Admin sees active requests and bidding rooms.
4. Admin sees homeowner eligibility status placeholders.
5. Admin sees savings analytics.
6. Admin sees provider activity overview.

## Early UI Requirement

This should be a preview/analytics dashboard.
Even though there is no direct screenshot for the HOA admin flow, Claude should extend the same screenshot-based theme:

- warm light background
- dark summary surfaces
- white rounded cards
- blue primary actions
- orange attention callouts when needed

No real admin controls or database writes yet.
