# Homeowner Workflow

## Ideal Flow

1. User sees a splash/value screen.
2. User creates an account.
3. User selects the Homeowner role.
4. User completes area verification.
5. User reaches the homeowner dashboard.
6. User opens the AI assistant flow.
7. User describes a service need.
8. AI placeholder suggests categories and grouping.
9. User reaches a request-posted confirmation screen.
10. User opens the neighborhood chat thread.
11. User enters the live bids screen.
12. User confirms a booking.
13. User follows service tracking.
14. User can later open My Bids and Profile from bottom tabs.

## Early UI Requirement

This workflow should feel real using mock data only and should visually match the provided homeowner mobile screenshots.

Required UI characteristics:

- off-white background
- dark top summary cards
- blue CTA buttons
- orange live or urgent status bars
- white rounded cards
- bottom tab bar with four main destinations

No real auth, AI, DB, or WebSockets.
