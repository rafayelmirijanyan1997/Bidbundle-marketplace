# Service Provider Workflow

## Ideal Flow

1. Provider enters the provider jobs screen.
2. Provider sees open bidding cards with urgency indicators.
3. Provider opens an opportunity detail screen.
4. Provider reviews the price range, timing, and grouping context.
5. Provider submits a bid from the dedicated bid-entry screen.
6. Provider checks the provider dashboard for revenue, win rate, and active bids.
7. Provider uses bottom tabs to move between My Bids, Reviews, and Profile.

## Early UI Requirement

Use mock jobs and mock bids.
The UI should match the provider reference screens:

- off-white page background
- dark navy summary cards
- white job cards with light borders
- orange urgency banners
- strong blue action buttons
- clean segmented filters and compact metrics

Do not implement real provider verification or payments.
