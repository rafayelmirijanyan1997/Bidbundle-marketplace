# User Roles

## Homeowner

Primary user.

Can:
- join a neighbourhood/community
- post service requests
- view active service groups
- join bidding threads
- compare provider bids
- confirm interest in a winning bid
- view history and renewals

## Service Provider

Can:
- view eligible group jobs
- submit bids
- revise bids during a bidding window
- view reputation metrics
- track won/lost bids

## HOA Admin

Optional early role.

Can:
- view community activity
- approve/verify homeowners
- monitor service categories
- view savings and participation analytics

## Initial Priority

Build UI for all three roles, but keep backend behavior mocked.

Priority order:
1. Homeowner experience
2. Provider bidding experience
3. HOA admin overview
