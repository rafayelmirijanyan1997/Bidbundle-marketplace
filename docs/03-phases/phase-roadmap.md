# Phase Roadmap

## Phase 0 — Project Planning and Setup

Goal: establish repo rules, app structure, design direction, and task workflow.

Tasks:
1. Confirm website-first strategy.
2. Let Claude propose UX sitemap.
3. Create initial frontend project if none exists.
4. Add responsive design system foundation.
5. Add mock data/service placeholders.

## Phase 1 — Public Website and App Shell

Goal: create polished initial website structure.

Tasks:
1. Landing page.
2. Role selection page.
3. Responsive layout/navigation.
4. Shared design system components.
5. Basic routing.

## Phase 2 — Homeowner Experience

Goal: build the primary user journey.

Tasks:
1. Homeowner onboarding.
2. Homeowner dashboard.
3. Community chat mock.
4. Create service request flow.
5. AI matching placeholder.
6. Bidding room.
7. Bid comparison and confirmation.

## Phase 3 — Service Provider Experience

Goal: build provider-side bidding workflow.

Tasks:
1. Provider onboarding.
2. Provider dashboard.
3. Available group jobs.
4. Submit/revise bid UI.
5. Provider reputation and history.

## Phase 4 — HOA Admin Preview

Goal: build admin visibility and trust features.

Tasks:
1. HOA admin dashboard.
2. Eligibility review placeholder.
3. Community analytics.
4. Savings overview.

## Phase 5 — UX Polish and Responsive QA

Goal: make the website feel complete on laptop and mobile browsers.

Tasks:
1. Mobile navigation polish.
2. Empty/loading/error states.
3. Responsive QA.
4. Accessibility pass.
5. Copy polish.

## Phase 6 — Later AI/Database Integration

Goal: only after UI/UX is stable.

Potential tasks:
1. Authentication.
2. Database schema/API.
3. AI request parsing.
4. Real-time bidding.
5. Notifications.
6. Maps/locality matching.
